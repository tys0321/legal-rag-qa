# M3.2 交付说明：轻量律所

## 实现内容

1. **MySQL 表**：`firms`、`firm_members`；同步 `users.firm_id`
2. **创建律所**：`POST /api/firms`（仅 approved 律师；一人一所）
3. **邀请成员**：`POST /api/firms/{id}/members`（仅 owner，按用户名邀请）
4. **查看**：`GET /api/firms/me`、`GET /api/firms/{id}`
5. **所内案源**：`GET /api/leads?scope=firm`  
   条件：同所成员已认领且 `firm_visible=1`
6. **`/auth/me`** 增加 `firm_id` / `firm_name` / `firm_role`

## 主要文件

- `backend/app/repositories/firms.py` / `database.py`
- `backend/app/api/firms_api.py` / `schemas/firm.py`
- `backend/app/repositories/leads.py`（`list_for_firm` / `can_view_lead`）
- `backend/tests/test_m3_firms.py`
