评测指标是「检索 top-k 标题是否包含期望法规关键词」，用来代理引用准确率。它不代替人工抽检大模型回答是否写对了法条。


第二条是不依赖向量库的词面模式，此前结果也是 35/35。

## 5. 检索实现

| 条件 | 行为 |
|---|---|
| `data/models` 中已有 fastembed 缓存 `Qdrant/bge-small-zh-v1.5` | 离线混合检索（稠密 + BM25 + 条款） |
| 无可用模型或向量库为空 | 扫描 `data/kb` 做词面检索，避免下载模型时卡住 |

配置模型名为 `BAAI/bge-small-zh-v1.5`，fastembed 实际使用上述 Qdrant ONNX 缓存。

## 7. 已知边界

1. **知识库规模**：只入库了 16 部摘录。PRD 中的国家级种子库（约 50–100 部）和桌面全量法规目录尚未入库，地方法规按约定默认不入。
2. **向量落盘**：检索数据在本机 `data/vectorstore`（已 gitignore）。换机器需要重新执行入库脚本，并保证模型缓存在 `data/models`。
3. **合同审查、其余场景分类**：按优先级只做占位，页面不会给出审查结论。
4. **演示时延**：完整问答走 DeepSeek，慢路径大约十余秒，符合 PRD 允许的 10–30 秒。
5. **Compose 中的 Qdrant**：服务已启动并出现在健康检查里；当前召回实现仍是本地向量文件，不是 Qdrant 集合查询。

## 8. 演示顺序（建议）

1. 打开 http://127.0.0.1:8081/ ，用 tys 登录。
2. 用户版提问「公司拖欠工资怎么办」，查看引用、免责和风险提示。
3. 打开法规检索、类案参考、意见书、文书、计算器。
4. 发一条案源，切到律师版认领并模拟联系后关闭。
5. 管理后台查看反馈列表。
6. 打开「合同审查」，确认为未开放。
