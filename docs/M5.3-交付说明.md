# M5.3 交付说明：法律计算器 ×5

## 实现内容

1. **配置**：`configs/calculators.json`（5 类 + LPR/倍率等可调参数 + 强制提示文案）
2. **API**
   - `GET /api/calculators` 列表
   - `GET /api/calculators/{id}` 字段定义
   - `POST /api/calculators/{id}` 输入参数 → 估算结果
3. **首批计算器**
   - 诉讼费（民事财产案件分段累进，可选减半）
   - 利息/逾期（民间借贷，可按 LPR×4 封顶）
   - 工伤赔偿估算（简版：一次性伤残补助金等）
   - 交通事故医疗费累加（简版）
   - 劳动加班费（简版：1.5 / 2 / 3 倍）
4. **边界**：结果区强制「估算仅供参考…」
5. **前端**：用户版「计算器」页

## 主要文件

- `configs/calculators.json`
- `backend/app/services/calculators.py` / `api/calculators_api.py` / `schemas/calculator.py`
- `backend/tests/test_m5_calculators.py`
