# M4.1 交付说明：法规检索产品化

## 实现内容

1. **API**：`GET /api/laws/search?q=&top_k=`（需登录）
2. **检索链路**：复用问答同款 **hybrid**（BM25 + 稠密向量 + 条款精确 + 重排）
3. **前端**：用户版「法规检索」页，展示标题/条款/效力/匹配通道与原文摘录

## 主要文件

- `backend/app/api/search_api.py` / `schemas/search.py`
- `backend/tests/test_m4_laws.py`
- `frontend/src/components/LawsSearchPanel.tsx`
- `frontend/src/api/client.ts`（`searchLaws`）

## 测试

```bash
cd backend
pytest tests/test_m4_laws.py -q
```

结果（本机）：**3 passed**（鉴权依赖注入 + `hybrid_search` mock；真实检索需 Docker MySQL/Qdrant 与已入库向量）。
