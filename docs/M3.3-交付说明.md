# M3.3 交付说明：案源 / 律所前端闭环

## 实现内容

1. **用户版**
   - 子页：AI 咨询 / 发案源 / 我的案源
   - 发布需求（场景、地区、摘要、联系方式脱敏、所内可见）
   - L2「转律师」CTA → 可一键「发布案源需求」
2. **律师版**
   - 案源广场：匹配分排序、筛选、认领、站内信、模拟中间号、关闭
   - 所内案源：`scope=firm`
   - 轻量律所：创建 / 邀请成员（owner）
   - pending 只读可浏览广场，不可认领/联系
3. **API 客户端**：`listLeads` / `createLead` / `claimLead` / `contactLead` / `createFirm` 等

## 主要文件

- `frontend/src/components/LeadPublishForm.tsx` / `MyLeadsPanel.tsx` / `LeadPlaza.tsx` / `FirmPanel.tsx`
- `frontend/src/components/LawyerPanel.tsx` / `MainView.tsx` / `MessageBubble.tsx`
- `frontend/src/api/client.ts` / `types.ts`
- `frontend/src/styles/app.css`（M3 样式）

## 测试

后端回归（本机）：

```bash
cd backend
pytest tests/test_m3_leads.py tests/test_m3_firms.py -q
```

前端：本机 `npm install` 环境异常时未能完成 `tsc`/`build`；UI 按现有 Vite+React 模式接入，建议确认后执行：

```bash
cd frontend
npm install
npm run typecheck
npm run build
```

手动联调路径：用户发案源 → 律师版广场认领 → 站内信/中间号 → 我的案源看事件；律所邀请后看「所内案源」。
