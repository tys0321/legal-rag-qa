# M5.1 交付说明：法律意见书

## 实现内容

1. **API**：`POST /api/opinions/generate`
2. **链路**：风险分级 → **混合检索** → **LLM** 结构化生成 → 引用验证
3. **结构**：案情梳理 → 法律分析 → 行动建议 → 免责声明
4. **水印**：`AI 生成草稿，须律师审核，不构成正式法律意见`
5. **L1**：强拦截，不生成操作建议
6. **前端**：用户版「意见书」页（可复制 Markdown）

## 主要文件

- `backend/app/services/opinion.py` / `api/opinions_api.py` / `schemas/opinion.py`
- `backend/tests/test_m5_opinion.py`
- `frontend/src/components/OpinionPanel.tsx`
