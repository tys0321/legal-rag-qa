# M3.1 交付说明：案源后端闭环

## 实现内容

1. **MySQL 表**：`leads`、`lead_events`（联系方式脱敏存储；事件记录状态流转/站内信/模拟中间号）
2. **发布**：`POST /api/leads`（用户发需求 → `open`/`draft`）
3. **匹配列表**：`GET /api/leads?scope=plaza`（场景 ∩ 擅长 + 地区打分排序）
4. **认领**：`POST /api/leads/{id}/claim`（仅 `approved` 律师；不可认领自己的）
5. **模拟联系**：`POST /api/leads/{id}/contact`
   - `channel=inbox`：站内信
   - `channel=virtual_number`：生成 `400-xxxx-xxxx` 模拟中间号
6. **状态机**：`draft → open → claimed → in_contact → closed / cancelled`

## 主要文件

- `backend/app/repositories/leads.py` / `database.py`（表结构）
- `backend/app/api/leads_api.py` / `schemas/lead.py`
- `backend/tests/test_m3_leads.py`
