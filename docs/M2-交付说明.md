# M2 交付说明：双端认证 + 风险分级 + 槽位

## 实现内容

1. **律师认证**：提交执业证号/地区/擅长领域 → `pending` 只读 → 管理员审核 → `approved`
2. **用户版/律师版顶栏切换**（同壳）；待审只读提示
3. **免责声明三位置**：顶部 banner + 每条回答末尾 + 首次登录弹窗确认
4. **风险分级**
   - L1：人身安全/刑事等 → 强拦截，不给具体操作建议
   - L2：标的 ≥ 50 万等 → 可回答但强制「转律师」CTA
   - L3：普通民事 → 正常 RAG
5. **七场景槽位引导**（`configs/scenes.json`）：劳动/租房/婚姻/交通事故/消费/行政诉讼/合同

## 主要文件

- `backend/app/services/risk.py` / `slots.py`
- `backend/app/repositories/lawyers.py` / `api/lawyer_api.py`
- `frontend/.../MainView.tsx` / `LawyerPanel.tsx` / `DisclaimerModal.tsx`
