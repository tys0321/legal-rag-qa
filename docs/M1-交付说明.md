# M1 RAG 强化交付说明

## 实现内容

1. **混合检索**：条款精确匹配 + 稠密向量 + BM25，RRF 融合（`hybrid_retrieve.py` / `bm25_index.py`）
2. **重排序**：默认 `heuristic`；可配 `llm` / `cross_encoder`（`rerank.py`，`RERANK_MODE`）
3. **编-章-节-条分块**：`chunker.py` 写入 `bian/chapter/section/article` 元数据
4. **引用验证**：非法 `[n]`、材料中不存在的《法》第X条剥离（`citation_verify.py`）
5. **自批评**：第二轮 LLM 质检（`critic.py`，`CRITIC_ENABLED`，失败则降级跳过）
6. **置信度**：`high/medium/low` 返回 API，前端徽标展示

## 测试

```bash
pip install -r requirements.txt
cd backend
pytest tests/test_m1_rag.py tests/test_rag.py tests/test_auth.py -q
```

## 配置要点（.env）

```
RERANK_MODE=heuristic   # 或 llm / cross_encoder
CRITIC_ENABLED=true
HYBRID_CANDIDATE_K=20
```
