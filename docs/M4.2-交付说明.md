# M4.2 交付说明：类案卡

## 实现内容

1. **API**：`GET /api/cases/search?q=&top_k=`（需登录）
2. **检索**：复用 `VectorStore.search_cases`（稠密向量 + 司法解释/批复/指导案例等特征过滤）
3. **卡片类型**：`judicial_interp` / `guiding_case` / `reply` / `decision` / `reference`
4. **边界文案**：返回 `notice`，明确不以「法院判决书原文」自称（PRD 5.3）
5. **前端**：用户版「类案参考」页

## 主要文件

- `backend/app/api/search_api.py` / `schemas/search.py`
- `backend/tests/test_m4_cases.py`
- `frontend/src/components/CasesSearchPanel.tsx`
