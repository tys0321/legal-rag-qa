# M0 基建交付说明

## 实现内容

1. **业务库迁移至 MySQL 8**（淘汰 SQLite `app.db` 作为主库）
   - `backend/app/repositories/database.py` 使用 PyMySQL
   - 保留 `?` 占位符 API，层内转 `%s`
   - 表：users / tokens / sessions / messages / admin_logs（预留 firm_id、meta_json）
2. **配置**：`.env.example` 增加 `MYSQL_*`、`VECTOR_BACKEND`、`QDRANT_*`、`MAX_HISTORY_ROUNDS=12`
3. **备份**：快照改为打包 `mysql_dump.json` + vectorstore + uploads
4. **Docker Compose**：`deploy/docker-compose.yml`（mysql / qdrant / api / web）
5. **健康检查**：`GET /api/health`
6. **迁移脚本**：`scripts/migrate_sqlite_to_mysql.py`
7. **烟测**：`scripts/smoke_m0.py`

## 本地验证步骤

```bash
# 1. 启动 MySQL（及可选 Qdrant）
cd legal-rag-qa
docker compose -f deploy/docker-compose.yml up -d mysql qdrant

# 2. 安装依赖并配置
pip install -r requirements.txt
copy .env.example .env   # 填写 DEEPSEEK_API_KEY；MYSQL 默认即可

# 3. 若有旧 SQLite 数据
python scripts/migrate_sqlite_to_mysql.py

# 4. 烟测
python scripts/smoke_m0.py
```
