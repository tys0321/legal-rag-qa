# M7.2 交付说明：检索兜底 + 离线混合检索

## 背景

1. 嵌入模型首次下载受网络限制时，法规检索/问答易卡住或无结果。
2. fastembed 实际缓存目录是 `Qdrant/bge-small-zh-v1.5`，与配置名 `BAAI/bge-small-zh-v1.5` 不同，易误判「未就绪」。

## 实现

1. `lexical_kb.py`：扫描 `data/kb`（含 `eval_core`），条款粗切 + 中文 n-gram
2. `hybrid_retrieve`：向量为空或无命中时词面兜底；无本地模型时跳过稠密通道
3. `embeddings.py`：按 Qdrant 缓存目录判定就绪；就绪则 `local_files_only=True` 离线加载
4. `GET /api/laws/search`：可返回 `backend=hybrid` 或 `lexical`
5. `scripts/ingest_eval_core.py`：小批量入库（网络可用时）

## 测试

```bash
cd backend
pytest tests/test_lexical_kb.py tests/test_m4_laws.py -q
```
