# M5.2 交付说明：文书模板 ×8

## 实现内容

1. **配置**：`configs/document_templates.json`（8 种 + 水印/免责）
2. **API**
   - `GET /api/templates` 列表
   - `GET /api/templates/{id}` 字段定义
   - `POST /api/templates/{id}` 槽位填充 → Markdown
3. **首批文书**：民事起诉状、答辩状、劳动仲裁申请书、离婚协议（框架）、租赁合同补充协议、消费投诉书、律师函（框架）、授权委托书
4. **输出**：可复制 Markdown；水印「AI 生成草稿，须律师审核」；未填槽位显示「【待填写】」
5. **前端**：用户版「文书」页（选模板 → 表单 → 预览/复制）

## 主要文件

- `configs/document_templates.json`
- `backend/app/services/templates.py` / `api/templates_api.py` / `schemas/template.py`
- `backend/tests/test_m5_templates.py`
- `frontend/src/components/TemplatesPanel.tsx`
